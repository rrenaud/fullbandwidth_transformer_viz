An explainer of arXiv:2608.08888 — Full-Bandwidth Transformer

Depth is parallel while you train it. It's already sequential once you run it.

Autoregressive training sweeps one layer at a time across every token at once. Autoregressive inference sweeps one token at a time through every layer. Standard decoding forces inference to imitate training's rule that a layer can't see a deeper layer's output from an earlier position — a rule training needed for its parallelism, and inference, being sequential over tokens anyway, gets nothing from keeping. Why training needs the rule

Write the hidden state of token t at layer ℓ as h[t,ℓ]. Training processes a whole sequence with teacher forcing: it runs layer 1 for every position at once, then layer 2 for every position at once, and so on. That parallel sweep is only legal if no layer needs a deeper layer's output from an earlier position that hasn't been computed yet — formally,

h[t, ℓ] cannot read h[t′, ℓ′]  for  t′ < t  and  ℓ′ ≥ ℓ

the paper's depth-frozen constraint. It's the reason the grid above fills in row by row instead of column by column during training.

Why inference doesn't need it

Generation is already sequential over tokens — you can't sample token t+1 before you know token t. By the time inference starts on a new token, every earlier column in the grid is already sitting there fully computed, top layer included, in the KV cache. Standard decoding still squeezes the handoff to the next token through the sampled token id — at most log₂|V| bits — and lets the rest of that finished column evaporate.

"Sequential computation is required only across layers, not across tokens. At decoding time… generation is already sequential over tokens, so the constraint buys nothing." Full-Bandwidth Transformer, arXiv:2608.08888

That's the pessimization: inference pays the depth-frozen constraint's cost (recomputing each token's stack from a thin token embedding) without getting its benefit (parallelism across tokens), because inference was never going to be parallel across tokens in the first place.

Widening the channel

The paper's fix, latent feedback, reuses the discarded top-layer state instead of only the sampled token. It fuses the previous top-layer state ht−1 with the new token embedding et through a gated linear unit and feeds that fused vector in as the next input — the violet band in the channel above, riding alongside the token id rather than replacing it:

et ⊗ ht−1  =  WUht−1  ⊙  σ(WGet)

No extra transformer-block evaluations per generated token, no change to the KV cache, no change to the language-modeling objective — just a wider handoff between one decoding step and the next.
