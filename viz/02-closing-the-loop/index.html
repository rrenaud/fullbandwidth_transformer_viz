Why the loop needs unrolling

  • One pass can't see its own latents. Teacher forcing runs every position at once, but position t wants zt−1 — a top-layer state that doesn't exist until the pass is over. So the pass uses the previous pass's latents, then runs again.
  • The loop closes one token per pass. Position 1 needs no latent, so it is exact from pass 1. Its latent makes position 2 exact in pass 2, and so on. Past that wavefront the error is only multiplied by the contraction factor ρ each pass — which is why a handful of passes suffices instead of T.
  • Inference pays none of it. Decoding is sequential anyway: zt−1 is already sitting there when step t starts. The iteration is a training-time cost — — buying a wide channel that is free at generation time.
Each block is one full teacher-forced pass over the same sequence; the wire leaving the top-layer row wraps around and re-enters the next pass's inputs, shifted one position.
