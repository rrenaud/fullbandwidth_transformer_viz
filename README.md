# Full-Bandwidth Transformer — interactive visualizations

**Live site: https://rrenaud.github.io/fullbandwidth_transformer_viz/**

Interactive explainers, built as self-contained HTML/JS/SVG pages, for
[Full-Bandwidth Transformer](https://arxiv.org/abs/2608.08888) (arXiv:2608.08888) —
why autoregressive transformers get full bandwidth *across tokens* but only a
narrow, discrete channel *across depth* between decoding steps, and how the
paper reopens it.
